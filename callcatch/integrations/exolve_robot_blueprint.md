# Блюпринт сценария для голосового робота МТС Exolve

Сценарий собирается в low-code редакторе робота Exolve (drag-and-drop).
Робот умеет ASR/TTS/NLP и HTTP-запросы к внешним сервисам в ходе диалога —
это всё, что нужно: мозг остаётся у нас, робот только «говорит и слушает».

Доступ к редактору выдаёт Exolve (может потребоваться запрос через
менеджера/поддержку: 8-800-555-40-00 или чат в ЛК). Стоимость: разовая за
создание робота + от ~0,21 ₽/мин голосового трафика.

## Схема сценария (узлы редактора)

```
[Входящий звонок]
   │
   ▼
[HTTP-запрос]  POST https://ВАШ-СЕРВЕР/api/voice/start?token=ТОКЕН
   │           body: {"phone": "{{caller_id}}"}
   │           сохранить: session_id, say, action
   │
   ├─ action == "reject" ──► [Завершить звонок]   (трубку не поднимать/сброс;
   │                          SMS-догон бэкенд уже запустил)
   ├─ action == "hangup" ──► [Синтез речи: {{say}}] → [Завершить звонок]
   ▼
[Синтез речи: {{say}}]      голос: женский «живой» (Алёна/аналог)
   │
   ▼
[Распознавание речи]        ожидание фразы, таймаут тишины 15 сек
   │                        по таймауту → [HTTP end] → [Завершить]
   ▼
[HTTP-запрос]  POST /api/voice/utterance?token=ТОКЕН
   │           body: {"session_id": {{session_id}},
   │                  "text": "{{asr_text}}",
   │                  "elapsed_sec": {{call_duration}}}
   │           сохранить: say, action
   │
   ├─ action == "continue" ──► [Синтез речи: {{say}}] → назад к [Распознавание]
   └─ action == "hangup"  ──► [Синтез речи: {{say}}]
                                 │
                                 ▼
                          [HTTP-запрос] POST /api/voice/end?token=ТОКЕН
                                 │      body: {"session_id": {{session_id}},
                                 │             "duration_sec": {{call_duration}}}
                                 ▼
                          [Завершить звонок]
```

## Обязательные настройки

- **Запись разговора**: включить (уведомление «звонок записывается» уже в
  приветствии от бэкенда); хранение записей — в РФ (Exolve).
- **Страховочный лимит длительности звонка** в настройках робота: 6 минут
  (бэкенд завершает на 5-й — это подстраховка на случай сбоя HTTP).
- **Цикл** «распознавание → utterance → синтез» ограничить 15 итерациями
  (бэкенд отдаст hangup на 12-й реплике — снова подстраховка).
- **Ошибка HTTP** (бэкенд недоступен): синтезировать «Простите, я вас записала,
  мастер перезвонит» → завершить. Клиент не должен слушать тишину.
- **Переменные**: `caller_id` (номер звонящего), `call_duration` (секунды с
  начала звонка) — точные имена смотреть в редакторе Exolve.

## Что проверить на первом тестовом звонке

1. `start` приходит с нормализуемым номером (+7 / 7 / 8 — бэкенд поймёт любой).
2. Латентность цепочки «ASR → HTTP → TTS» — пауза до ответа не больше ~1,5 сек.
   Если больше — включить в редакторе «филлеры» («секундочку…») или потоковый TTS.
3. `elapsed_sec` реально растёт (иначе мягкое сворачивание не сработает).
4. После записи пришло SMS-подтверждение (провайдер exolve, см. .env).
5. Расшифровка появилась в уведомлениях админа и на дашборде (/lead?id=...).
