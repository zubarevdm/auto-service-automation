# Подключение телефонной платформы к голосовому ассистенту

Мозг ассистента живёт в callcatch (`/api/voice/*`), платформа делает три вещи:
принять звонок, превратить речь в текст и озвучить ответ. Любая платформа
подключается по одному контракту.

## Выбор платформы (важно: 152-ФЗ)

Записи разговоров и номера — персональные данные; ст. 18 ч. 5 152-ФЗ требует
их хранения в базах на территории РФ. Поэтому:

| Вариант | Статус | Комментарий |
|---|---|---|
| **МТС Exolve** (exolve.ru) | ✅ рекомендуемый | юрлицо и данные в РФ, голосовой робот + ASR/TTS + Telecom API; имя МТС продаёт само |
| Novofon / Sipuni / ZEON | ✅ запасные | российские, тот же класс |
| Свой Asterisk + SpeechKit/VoiceKit | ✅ максимум контроля | все записи на вашем VPS (РФ); больше DevOps |
| Voximplant (voximplant.ru) | ⚠ только после проверки | платформа работает в РФ, но HQ в США — требуйте в договоре подтверждение локализации данных; для продаж слабая позиция |

Сценарий `voximplant_scenario.js` оставлен как эталонная реализация адаптера —
по нему видно, что должен делать адаптер любой платформы.

## Контракт (3 вызова HTTP POST, JSON, `?token=CC_WEBHOOK_TOKEN`)

**1. Звонок пришёл** → `POST /api/voice/start` `{"phone": "+7..."}`
Ответ: `{"session_id": N, "say": "приветствие", "action": "continue"}`.
`action: "reject"` — трубку НЕ поднимать (стоп-лист или дневной бюджет исчерпан;
бэкенд уже запустил SMS-догон клиента). `action: "hangup"` — озвучить `say`
и положить трубку (лимит звонков с номера).

**2. Клиент сказал фразу** (распознанную ASR) →
`POST /api/voice/utterance` `{"session_id": N, "text": "...", "elapsed_sec": 42}`
Ответ: `{"say": "...", "action": "continue" | "hangup"}`.
`elapsed_sec` обязателен — по нему движок делает мягкое сворачивание (180 с)
и жёсткое завершение (300 с).

**3. Звонок закончился** (любой причиной) →
`POST /api/voice/end` `{"session_id": N, "duration_sec": 75}`
Бэкенд посчитает себестоимость, отправит администратору расшифровку,
а клиенту — SMS-подтверждение, если была запись.

## Обязанности адаптера

- отвечать на вызов только после `start` (уважать `reject`);
- таймаут тишины ~15 с (автообзвонщики) → `end` + hangup;
- страховочный собственный таймер жёсткого лимита (сервер тоже следит, но
  часами владеет платформа);
- запись разговора включать только при уведомлении в приветствии (оно уже
  в тексте `say`) и хранить в РФ;
- голос TTS — женский «живой» (Yandex Alena / SaluteSpeech / VoiceKit).

## Чек-лист запуска на МТС Exolve

1. Аккаунт на exolve.ru, виртуальный номер.
2. Сценарий голосового робота: вход → HTTP-запрос `start` → TTS `say` →
   ASR → HTTP `utterance` → TTS `say` → цикл; завершение → HTTP `end`.
   (В Exolve это собирается в их конструкторе робота или через Voice API —
   выбрать по фактическим возможностям тарифа.)
3. У сервиса-клиента: переадресация непринятых через ~30 с на номер Exolve.
4. Тест: позвонить, не взяв трубку на основном номере, — услышать Алёну,
   договориться о записи, получить SMS, увидеть запись на дашборде.
