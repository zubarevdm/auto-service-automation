# Win-back система для автосервисов

Возвращает уснувших клиентов автосервиса: сегментирует базу по правилам,
готовит персональные сообщения цепочками, доказывает владельцу каждый
возвращённый заезд рублём (атрибуция) и печатает отчёты, которыми продаётся
продление.

Оплата труда системы — процент от фактически возвращённой выручки:
владелец не рискует ничем, это главный аргумент холодной продажи.

## Установка

Python 3.10+, единственная зависимость:

```
pip install openpyxl
```

## Быстрый старт: демо для показа

```
python -m winback demo
```

Создаёт синтетическую базу автосервиса (1400 клиентов), прогоняет весь
конвейер за «прошедший месяц» и кладёт в `output/`:

- `демо_аудит.html` — отчёт «сколько денег спит в базе» (показывать при продаже);
- `демо_сообщения_волна1..3.xlsx` — сообщения с готовыми WhatsApp-ссылками;
- `демо_отчёт_кампании.html` — итоги: кто вернулся, выручка, комиссия.

## Рабочий цикл с реальным сервисом

**1. Аудит (бесплатный крючок при продаже).** Берёте у владельца выгрузку
из CRM (Excel: клиент, телефон, авто, дата заказ-наряда, сумма, пробег,
работы — колонки распознаются автоматически, порядок не важен):

```
python -m winback audit выгрузка.xlsx
```

→ `output/аудит_спящих_денег.html` — открываете владельцу: «вот сколько
у вас спит, вот наша модель — процент с возвращённого».

**2. Запуск кампании.**

```
python -m winback import выгрузка.xlsx     # загрузка в рабочую базу
python -m winback segment                  # сводка по сегментам в консоль
python -m winback messages                 # план цепочек + Excel на сегодня
```

`output/сообщения_<дата>.xlsx` — колонка «WhatsApp-ссылка» открывает чат
с уже подставленным текстом: рассылка руками занимает минуты. Каждый
следующий день запускаете:

```
python -m winback send                     # сообщения, у которых подошёл срок
```

**3. Клиент ответил или записался** — глушим его цепочку:

```
python -m winback stop +79161234567            # просто остановить касания
python -m winback stop +79161234567 --optout   # полная отписка (согласие=нет)
```

**4. Атрибуция и отчёт (раз в неделю).** Берёте свежую выгрузку из CRM:

```
python -m winback attribute свежая_выгрузка.xlsx
python -m winback report
```

→ `output/отчёт_кампании.html`: касания, возвращённые клиенты поимённо,
выручка, ваша комиссия. Правило атрибуции: заезд в течение 14 дней после
касания (настраивается в `winback/config.py`).

## Настройка под конкретный сервис

Всё в [winback/config.py](winback/config.py): название и телефон сервиса,
офферы по сегментам, пороги сегментации, размер комиссии, окно атрибуции.
Тексты сообщений — в [winback/messages.py](winback/messages.py) (`TEMPLATES`).

## Правила сегментации (то, что объясняете владельцу)

Пороги считаются от личного среднего интервала клиента, не от календаря:

| Сегмент | Правило | Оффер |
|---|---|---|
| По пробегу | накат с последнего визита ≥ 9000 км (оценка по истории пробегов) | конкретное ТО с ценой |
| Сезонные | месяц переобувки + «шинился» у нас | слот без очереди |
| Спящие | 1.5–2.5 личного интервала (fallback 6–9 мес) | бесплатная диагностика |
| Уходящие | 2.5–4 интервала, был регулярным (3+ визита) | скидка 15% с дедлайном |
| Потерянные | дольше 15 мес | одно сильное касание, не больше |

Клиент попадает только в один сегмент (приоритет сверху вниз), цепочка —
3 касания (потерянным — одно), после цепочки карантин 45 дней.
